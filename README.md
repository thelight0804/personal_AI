# personal_AI
AWS EC2에서 24시간 실행되는 개인 AI 비서 서버를 구축하는 프로젝트입니다.
개인 메신저를 통해 PC와 휴대폰에서 AI 비서와 대화하고, 파일을 관리할 수 있는 환경을 만드는 것이 목표입니다.
AWS와 Terraform의 학습 목적을 위해 코드 작성은 AI를 사용하지 않을 예정입니다.

## 아키텍처
배포가 완료된 뒤, 실제 생성된 AWS 리소스를 기준으로 아키텍처 다이어그램을 추가합니다.

## 기술 스택
- AI Assistant: OpenClaw
- Amazon Web Service
  - Amazon EC2, Amazon EBS, Amazon Bedrock, Amazon CloudWatch
- Terraform
- Docker
